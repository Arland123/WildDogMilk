合成野生狗奶

在线试玩：**https://arland123.github.io/WildDogMilk/**

把「合成大西瓜」玩法搬进超市冷柜的纯静态网页小游戏：十一级奶盒连锁合成，从野生马尿一路养到野生奶·终极进化版。

## 玩法

- 移动鼠标/手指瞄准，点击或松手投放
- 两盒同级的奶撞在一起，合成为更高一级
- 奶盒堆过警戒线持续 2 秒即结束
- 两盒终极狗奶相撞会一起炸掉，+1000 分
- 键盘：← → 瞄准，空格投放，R 重开

## 彩蛋：提示模式

**只有自己合成出第 11 级「野生奶·终极进化版」才会解锁**，解锁后永久记住（存 localStorage）。

解锁后顶部会出现「提示」小按钮，点一下给出本步推荐落点（绿色虚线）与下一盒的预估落点（蓝色虚线），
并显示预计能拿到的两步收益。提示在独立 Web Worker 里计算（约 0.3~1.5 秒），不阻塞游戏；
每次投放、重开、切难度后旧结果立即失效，不会展示过期建议。

实现位于 `js/hint/`：`physics.js`（可复用的物理内核，支持 720/750 两种高度）、
`solver.js`（候选枚举 + 物理回放 + 两步前瞻）、`worker.js`、`hint.js`（解锁、快照、绘制）。
主逻辑只增加了 4 个钩子：`__hintUnlock` / `__hintInvalidate` / `__hintDraw` / `__hintRequest`。

## 技术

- 无构建、无后端，直接打开 `index.html` 即可运行
- 物理：Matter.js 0.20.0（MIT，已本地化于 `lib/matter.min.js`）
- 渲染：Canvas 2D，四级贴图取自 `img/1.png`~`img/11.png`

python -m http.server 8000
