## 环境坑（重要，会复现）

- **GitHub 仓库名不能带中文**：`gh repo create 合成野生狗奶` 会把非 ASCII 全洗成 `-`，
  真的建出 `Arland123/-`。改用 `gh api -X PATCH repos/OWNER/- -f name=WildDogMilk` rename 救回。
  以后仓库名一律 ASCII，中文只放 description / README 标题。
- **本机 `git push` 到 GitHub 必失败**：`RPC failed; curl 55 Send failure: Connection was reset`
  （send-pack 阶段），重试 3 次 + `http.version=HTTP/1.1` + 大 postBuffer 都无效。
  但 **`gh api` 与 `git fetch/ls-remote` 正常**（写大包才断）。
  绕法：用 Contents API 逐文件上传 ——
  `gh api -X PUT repos/OWNER/REPO/contents/<path> --input payload.json`，
  payload `{message, content:base64, branch:"main", sha:<更新时必填>}`。
- 开启 Pages：`gh api -X POST repos/OWNER/REPO/pages -f "source[branch]=main" -f "source[path]=/"`；
  构建状态查 `repos/OWNER/REPO/pages/builds/latest` 的 `.status`（building → built，约 20s）。
